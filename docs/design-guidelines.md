# MechvibesDX — Design Guidelines & UI Principles

## 1. Visual Language
MechvibesDX uses a modern, sleek **glassmorphic design system** with vibrant accents, subtle borders, and backdrop blurs (`backdrop-filter: blur()`).

## 2. Color Palette & Typography
- **Theme Support**: Dark Mode, Glassmorphic Light/Dark, Cyberpunk, Retro, Custom User Accents.
- **Typography**: Clean sans-serif font stack (Inter / System UI font) for optimal legibility across High-DPI screens.
- **Micro-Interactions**: Smooth hover state transitions, active button presses, animated loading indicators for catalog downloads.

## 3. Responsive Layout & Window Constraints
- **Default Window Size**: `470px × 820px`
- **Min Height**: `600px`
- **Max Height**: `820px`
- **Native Window Controls**: Native macOS traffic light controls with custom titlebar integration.
